Sobre el curso

El desarrollo web es el proceso de crear y mantener sitios o aplicaciones que funcionan a través de internet.

Propósito del curso: Aprender el manejo de programas, el proceso completo de creación, construcción y mantenimiento de sitios y aplicaciones que funcionan en internet y se ven en los navegadores.

Temas del curso

Algunos temas que veremos en el curso:

  • Protocolo HTTP
  • HTML5 semántico
  • Hojas de estilo CSS
  • Control de versiones con Git y Github
